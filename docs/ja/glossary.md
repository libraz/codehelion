# 用語集

**baseline** — プロジェクトが受け入れた finding を記録したファイル。以降のスキャンはこれを読んで、その後に現れたものを報告します。指すのはグループ単位です。[baseline](baselines.md) を参照。

**boilerplate 分類** — 本体がどの形として認識されたか。単純な本体、転送だけの呼び出し、条件ひとつのディスパッチなど。抑制ポリシーが何をしようと記録されます。

**build variant** — 何かが作られたときの条件。source run は「ソースをどう読んだか」を表すものを持ち、成果物は「どうビルドしたか」を表す JSON manifest を自分で書きます。両者は並べて記録され、突き合わせることはありません。

**canonical member** — グループの基準になる出現箇所。一覧では `◆` が付きます。他のすべてのメンバーはこれに対して閾値を越えています。

**candidate** — 索引が提案し、まだ検証されていないペア。候補パイプラインは `-vv` が表示します。

**clone class（クローンの型）** — Type-1 / Type-2 / Type-3。[クローンの型](clone-types.md)を参照。

**clone group（クローングループ）** — 1 件の finding としてまとめて報告される出現箇所の集合。安定 ID をひとつ持ちます。

**cohesion** — 各メンバーが canonical member と一致している度合いではなく、メンバーどうしがどれだけ一致しているか。

**content entropy** — グループの内容がどれだけ変化に富むか。本物のルーチンと、同じ数トークンの退化した繰り返しを分けるために使います。

**duplicated tokens** — グループが canonical member を越えて繰り返しているトークン量。`--sort` が受け付ける軸のひとつです。

**finding ID** — 出現箇所ひとつの安定 ID。`-v` で `[finding <ID>]` として表示されます。グループの ID とは別です。

**fragment** — 本体全体ではなく、ひとつの本体の中にある文の連なり。

**gate（閾値）** — 候補がグループに入るために canonical member に対して越える必要のある類似度のしきい値。

**identifier agreement（識別子の一致度）** — 2 つの出現箇所の識別子がどれだけ重なるか。ユニット全体に対して測ります。一致度が高いのは、まだ誰も 2 つのコピーを分岐させていない状態です。

**lineage** — 内容の変化で ID が動いたとき、ある実行のグループが直前の実行のどのグループから引き継いだかを記録したリンク。

**near miss** — 閾値のすぐ下に落ちた候補。診断用として保持し、`--show-near-misses` が表示します。

**normalization（正規化）** — 比較の前にコメントと空白を除き、識別子とリテラルを書き換えること。リテラルの扱いは設定できます。

**occurrence（出現箇所）** — グループの重複が現れる 1 箇所。ファイル、行範囲、そして所属ユニット。

**posting** — 内容索引の項目。多すぎる unit が共有する posting list は、重複ではなく作業を提案するだけなので落とします。

**priority** — レポートを並べている合成された順位づけの値。clone confidence・maintenance risk・refactoring difficulty から導かれます。設定できるのは合成の仕方だけです。

**run（実行）** — 完了したスキャン 1 回。ローカルデータベースに、それを再現する id とともに記録されます。

**sibling** — グループの傍らに証拠として保持される未グループのユニット。canonical member に近いか、その正規化済みシグネチャに一致するものです。[グループ化](grouping.md)を参照。

**signature（シグネチャ）** — 関数の正規化された呼び出し形。珍しいあいだだけ証拠になります。

**split pair** — どの完全なグループにも入らない検証済みペア。完全なグループより後ろに報告されます。

**suppressed（抑制）** — ルールによって隠され、合計に計上されているもの。`--show-suppressed` が理由とともに一覧します。

**unit** — 本体ひとつ。関数やメソッド。

**verified savings** — 実ビルド 2 つのあいだで観測されたサイズ差を、名指しした 1 つのクローングループに帰属させた値。それ以外に何も違わないビルド対についてのみ言葉どおりの意味を持ちます。[calibration](calibration.md) を参照。
